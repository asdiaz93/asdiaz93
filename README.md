# Andrew Diaz

Founder of [RVERE AI](https://rvere.ai), an AI front office built for government offices, campaigns and businesses. Based in Dallas, TX.

## Background

I started my career at J.P. Morgan, then helped build practices at EY and Alvarez & Marsal, and later moved into advisory work in regulated financial services. That meant working with CEOs and boards, running large programs through a central PMO, and holding work to the quality and risk standards regulated industries require.

## How I build RVERE

I run RVERE's build the way I ran consulting programs. I set the scope, define what done looks like, and direct, review and approve the work, using AI coding tools to move at startup speed.

- **Scoped work.** Every change to the product starts as a tracked issue with a defined outcome and ships as a reviewed pull request.
- **Cross-model review.** Different AI models check each other's work, for the same reason good firms don't let the preparer sign off on their own work.
- **Automated checks.** Security, quality and permission checks run on every change to the product.
- **Clear accountability.** Product direction, priorities and what ships are my call.
